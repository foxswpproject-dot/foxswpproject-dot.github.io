Seaward Pirates Rclone

This is an informational page for a personal-use Google Drive OAuth desktop client, used with the open-source rclone file-management utility.

Purpose and functionality

The OAuth client allows its owner to authorize rclone on a local computer to access the owner's selected Google Drive account. Rclone can list, upload, download, copy, move, rename and delete files at the owner's direction, including files and backup archives for a private Seaward Pirates software project.

Authorization is performed by Google. OAuth access and refresh tokens are stored in the owner's local rclone configuration; this website does not request or receive them. This website is not a login portal and does not itself connect to Google Drive.

Data and permissions

The Google Drive permission requested by rclone may grant broad access to files in the connected account, so the owner grants authorization only to accounts they control and operates rclone locally. No Google Drive files, access tokens or project archives are published on this website.

For information about how Google user data is accessed, used, stored and disclosed in this setup, see the Privacy Policy.

Independent personal-use configuration; not affiliated with Google or the rclone project. This site contains no client secrets, access tokens or private project files.
