Privacy Policy

Application: Seaward Pirates Rclone

Last updated: November 4, 2026

Seaward Pirates Rclone is a private, personal-use OAuth 2.0 client configuration for the rclone desktop utility. It is used to access a Google Drive account authorized by the owner. It is not a public cloud storage service and does not operate an application backend.

Google user data accessed

When the owner explicitly authorizes rclone, the Google Drive API permission can allow rclone to see file and folder names, metadata, contents, and permissions in the connected Drive; it can also create, upload, download, modify, move, and delete files and folders as directed by the owner. The requested full Google Drive scope is used to work with existing folders and files, not solely newly created files.

Purpose and use

Google Drive data is used only for file management and backup actions initiated by the authorized owner, such as transferring software project archives between their computer and Google Drive. The client is not used for advertising, profiling, data analytics, or marketing.

Storage and security

OAuth access and refresh tokens are stored in the owner's local rclone configuration, which the owner is responsible for protecting. File contents can be transferred between the owner's local computer and their authorized Google Drive account during rclone operations. This informational website does not ask visitors to sign in, does not collect Google Drive data, and does not receive or store OAuth tokens, file contents, or Google account credentials.

Data disclosure and third parties

The owner does not sell, share, or transfer Google Drive user data to advertisers or data brokers. Data is transferred between the local rclone utility and Google Drive via Google's APIs. Google provides account authentication and Google Drive storage. This static website is hosted on GitHub Pages, which may handle ordinary website access information according to GitHub's privacy statement. No additional application analytics or tracking scripts are installed here.

Retention and control

The Google Drive owner controls their files, local copies and backups. They may revoke the OAuth connection in their Google Account security settings and remove the local rclone token/configuration. Revoking access stops new authorized API operations; it does not automatically erase previously transferred files or copies already stored locally or in Google Drive.

Limited use and changes

Access to Google user data is limited to the functionalities described above and to the owner's authorized instructions. The owner will update this page if the app's actual data handling changes. This is a personal configuration and is not affiliated with Google or the rclone maintainers.

Return to Seaward Pirates Rclone homepage. For questions about this personal OAuth client, use the support contact shown on its Google OAuth consent screen.
